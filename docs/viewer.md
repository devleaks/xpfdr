# Flight Data Recorder Viewer

The `fdr_viewer.html` page is a simple, straightforward HTML page for viewer FDR data files.

It has been optimized to view FDR files generated by the FDR X-Plane plugin.

Opening other valid FDR file, version 3 or 4 might work, but this page is not
a generic FDR viewer file.

FDR files generated by the X-Plane FDR plugin contains meta data and addtional
information that help build this page.

Open the `fdr_viewer.html` page and drop a `.fdr` or `.geosjon` file on it.

Enjoy.
